# 奇趣游园会｜五年级第4课《算法应用在身边》

这是40分钟、一人一机的2D课堂游戏。学生扮演小镇向导，依次帮游客**找活动、选路线、推荐下一站**，最后开办智慧服务亭。每一幕都需要根据游客需求作决定；错误选择会出现具体后果，学生可以修订，再用新条件检验。作品、活动积分、四项课堂回访和20题完整考核分别保存。

地图已采用更易辨认的三色路径和分叉节点；地图上的向导缩小到适合小镇比例，行走时正面、背面与侧面姿态会交替迈步。游客先通过短对话提出需要；学生回应后，才进入相应的搜索、带路或推荐操作。错误回应会保留并引出追问，不扣积分。

本课依据本机同课目录的《第4课 算法应用在身边.pdf》印刷页25—28及配套PPT；教学设计保存在本机的“备课方案”文件夹，教材与配套文件不随代码仓库上传。教学中的搜索排名、路线数据和推荐次数均为明确标注的简化模拟，不能作为真实平台算法或现实交通时间使用。

## 上课入口

需要教师电脑安装 **Node.js 22.13 或更高版本**。应用不需要安装第三方运行依赖。教师电脑与学生电脑接入同一局域网。

从 GitHub 获取的代码不包含真实学生名单和课堂记录。初次试运行可复制 `roster.example.json` 为 `roster.private.json`，此时只会出现两位虚构学生；正式上课再按下文“登录、数据与备份”导入受控名单。课堂记录不会上传到 GitHub。

已在另一台电脑部署时，更新程序请先保留该机的 `roster.private.json` 和 `runtime/`，再更新 GitHub 代码、重启课堂服务并刷新学生浏览器页面。更新代码不应清空已有学习记录。

**当前这台 Mac 已部署为登录后自动启动，使用8784端口。**上课前双击 `查看课堂网址.command`，读取当时的学生 IP 地址与服务状态。服务运行中时无需再双击 `启动课堂.command`，以免端口冲突。当前网络曾显示 `192.168.0.14`，地址会随网络变化，请以检查时显示的结果为准。

1. 在其他电脑部署时，macOS 双击 `启动课堂.command`；Windows 双击 `启动课堂-Windows.bat`。也可在本目录运行 `node --no-warnings server.cjs`。
2. 启动窗口会显示“学生局域网入口”，例如 `http://192.168.0.14:8784/`。把当次显示的地址发给学生；不要把示例IP当作固定地址。
3. 教师在**运行服务的这台电脑**打开 `http://localhost:8784/teacher`。教师大屏免密码。学生端没有大屏或测试入口，局域网设备请求教师页和管理接口会被服务端拒绝。
4. 在教师大屏右上方打开“隔离测试”，可任意选任务、试正确与错误路径、查看参考答案与服务卡量规。虚构状态只在教师浏览器内存中，不写学生成绩。

默认端口是8784。其他程序占用时，可设置 `PORT=9000` 后启动；教师网址与学生网址的端口随之变化。上课期间保持启动窗口运行；学校防火墙若询问是否允许 Node.js 访问局域网，应允许在可信课堂网络中访问。

本机自动启动配置保存在 `~/Library/LaunchAgents/com.jun.grade5.lesson4.festival.plist`，使用 `RunAtLoad` 与 `KeepAlive`。若更新了程序文件，需要重启该服务以载入新代码；手动停用时也应通过系统服务管理，而不是同时启动第二份服务。

## 40分钟安排

| 时间 | 内容 |
| --- | --- |
| 0—3分钟 | 登录、进入小镇，教师说明向导职责 |
| 3—10分钟 | 找活动：两个不同的游客需求、搜索与修订 |
| 10—19分钟 | 带游客：最快、最短、封路与新条件 |
| 19—25分钟 | 推荐：比较历史记录与当前明确需要 |
| 25—29分钟 | 智慧服务卡：选主题、匹配信息与作用 |
| 29—35分钟 | 四项课堂回访、对错误目标短回学 |
| 35—40分钟 | 分享典型选择、归纳、保存与缓冲 |

游戏探究约26分钟是**设计预估**，实际班级用时尚待试教。四项课堂回访在订正后再次验证时切换到另一套等目标情境。20题完整考核另有独立页面，建议课后或下一课完成；它不阻止本节课提交服务卡和保存记录。20题每次一卷，A/B两套交替，服务器评分；提交前只给题干和选项，提交后显示答案及解析。考核百分制与70分活动积分分开。

地图另有六个可以自由进入的应用体验馆，覆盖教材其余案例。学生可在图像识别馆观察无名称的叶片图卡、选择形状与颜色后比较候选；语言翻译馆查看固定短句怎样拆分为词块并组合；购物推荐馆改变浏览次数看排序；运动数据馆用同一组模拟读数调整峰值阈值；图像艺术馆实际改变图片像素；影像辅助馆调整阈值标记虚构图像中的亮点。每次运行保存输入与输出，教师可在学生详情中查看。图像识别、翻译、推荐、运动和影像辅助均为明确标注的教学简化模型；艺术馆则在浏览器中真实运行像素运算。影像亮点标记不构成医疗诊断。

40分钟课堂仍以三个游客委托和服务卡为必做；六个自由体验馆不扣主线完成率，也不额外发通关积分。可在课堂剩余时间选一馆比较前后变化，其余安排课后或下一课，不要求一节课逐馆刷完。教师电脑的隔离测试入口可直接选择任一馆演示，结果不写入学生记录。

## 登录、数据与备份

- 本地 `roster.private.json` 已从本项目的《五年级班级姓名名单.xlsx》导入，共501—504班212位学生。学生先选班级、再选该班姓名；可搜索或手动补录。名单文件含真实姓名，应仅保存在受控教师电脑或私有分发包中。
- `roster.example.json` 是虚构样例。要在新地点部署，随私有课堂包一起复制 `roster.private.json`；如果使用新版名单，保留原有学生 `id` 以继续关联历史记录。不要只依据姓名或班级重建旧身份，也不要因名单更新删除数据库。
- 服务端数据保存在 `runtime/classroom.sqlite`。该目录被 `.gitignore` 排除，不能放入公开仓库或学生分发的静态包。学生刷新、同一服务内换电脑登录后可恢复已同步进度；断网期间操作保存在当前浏览器并显示待同步，联网后按事件编号去重补传。若另一台电脑已有冲突更新，页面会提示导出本机记录后核对，不会悄悄覆盖。
- 学生可随时点“导出当前记录”；未完成主线也允许导出。学生切换身份前应确认“已保存到课堂”或先导出待同步记录。
- 在运行或停止服务时，均可在本目录运行 `node --no-warnings backup.cjs`，会通过 SQLite 一致性备份写入 `backups/`。迁移电脑时复制 `roster.private.json` 与最新的备份数据库，备份文件改名为新机 `runtime/classroom.sqlite` 后再启动。`backups/` 同样不进入公开仓库。

不应把无密码选名解释为安全账户认证。教师大屏与管理接口默认只允许本机访问；学校若要求教师在另一设备查看，需要另行配置受控访问范围和验证网络规则。

## 画面资源

`assets/` 中的地图、向导、游客、叶片图卡和服务亭为本课生成的2D素材。地图保留底图原有的三色铺装，不再叠加顶部黄色、紫色连接线。学生点击道路可让角色沿路行走，再点可从当前位置改道；点击地点标识会走到入口处。道路碰撞地图与场景标定：摊位、建筑、水面、花坛和舞台不能进入，门楼屋顶会遮挡从下面经过的角色。中心路封闭时自由行走会绕路，指定走B路线会停在围栏前。向上和横向行走会切换角色姿态与两幅交替行走帧。具体选型与道路边界见[移动引擎选型与实现](移动引擎选型与实现.md)。

寻路使用本地附带的 EasyStar.js 0.4.4，许可文件保存在 `vendor/easystarjs/LICENSE`，正式运行无需另外安装依赖。地图图片加载失败时，仍有简化地图、角色、地点按钮和完整任务操作。人物动画不承担判定；系统开启“减少动态效果”时仍沿道路移动，只关闭跳动和交替迈步。

本次素材由 Codex 内置图像生成工具产生。工具未向本任务提供可核实的具体模型版本，因此不标注为“image2.5”成果。最终生成提示词见[素材生成说明](assets/素材生成说明.md)。
